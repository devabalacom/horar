# Хорар — Astro AI

Страница хорарной астрологии в дизайн-системе aiastro.ru (токены, шрифты Involve/Anticva, шапка и подвал блога).

Сейчас это фронтенд: форма вопроса, реальный расчёт карты на момент вопроса в браузере (`astronomy-engine`, дома равные от ASC) и предварительный вывод по аспекту сигнификаторов. Толкование по книгам (RAG + LLM) и бэкенд — следующий этап.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- `src/lib/astro.ts` — расчёт карты
- `src/lib/judgement.ts` — сигнификаторы, аспекты, условия перед суждением
- `src/lib/content.ts` — темы, города, книги (названия — TODO), FAQ
- `MAIN_SITE_URL` — адрес основного сайта для логотипа и ссылок в подвале (по умолчанию https://aiastro.ru)
