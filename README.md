# Хорар — Astro AI

Страница хорарной астрологии в дизайн-системе aiastro.ru (токены, шрифты Involve/Anticva, шапка и подвал блога).

Флоу как в хорарных калькуляторах: тема вопроса (категория → подтема → дом квезита) → момент вопроса (по местному времени города) → город (поиск с координатами и часовым поясом) → карта. Все поля попадают в URL, ссылкой можно поделиться.

Расчёт идёт в браузере (`astronomy-engine`): дома по Региомонтану, правило 5° Лилли, день/ночь, планетный час, эссенциальные достоинства (триплицитности Лилли, египетские термы, халдейские лики), рецепции, главный аспект с проверкой рефранации по эфемериде, сроки по Лилли, следующий аспект Луны, условия перед суждением. Сверено с эталонной картой 20.10.2026 20:10, Ташкент.

Толкование по книгам (RAG + LLM) и бэкенд — следующий этап.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

- `src/lib/astro.ts` — карта: планеты, куспиды, планетный час, часовые пояса
- `src/lib/dignities.ts` — достоинства и рецепции
- `src/lib/aspects.ts` — аспекты, перфекция, рефранация, Луна без курса
- `src/lib/judgement.ts` — сводка: вердикт, проверки, сигнификаторы, сроки
- `src/lib/topics.ts` — темы и дома
- `src/lib/geo.ts` — поиск городов (Open-Meteo geocoding; TODO: свой бэкенд)
- `src/lib/content.ts` — книги (названия — TODO), FAQ
- `MAIN_SITE_URL` — адрес основного сайта (по умолчанию https://aiastro.ru)
